询价是在系统中获取酒店正式价格的方式。您提交住宿需求后，销售会根据需求整理一个或多个**报价方案**；您确认方案后，销售继续安排预订并生成订单。

整体流程：

1. 提交询价，状态为「待处理」；
2. 销售查看需求，如信息不全会将询价标记为「待补充」；
3. 销售出具报价方案，方案状态为「待确认」；
4. 您确认方案，方案变为「已确认」；
5. 销售完成预订，可在订单列表查看订单。

## 进入询价页面 {#entry}

有三种方式发起询价，可以根据手头信息选择：

| 方式 | 适用场景 | 操作 |
| --- | --- | --- |
| 人工询价 | 需求比较复杂、还没确定酒店，或想直接用文字描述需求 | 左侧菜单「业务 → 人工询价」 |
| 酒店页面发起 | 已经在酒店查询中找到目标酒店 | 在酒店卡片或酒店详情页点击「发起询价」 |
| 待询清单 | 已经在酒店详情中挑好了多个房型 | 打开待询清单，确认后发起询价 |

:::note
一次询价只能针对**一家酒店**。需要比较多家酒店时，请分别发起询价，或在人工询价中描述需求，让销售为您推荐。
:::

## 人工询价页面 {#manual}

人工询价页面分为左右两部分：左侧是「AI 智能对话」，右侧是「询价信息」表单。两边可以配合使用，最终以右侧表单的内容提交。

### 左侧：AI 智能对话 {#ai-chat}

在输入框中用自然语言描述住宿需求，例如：

> 下周五到周日，上海外滩附近，五星酒店，两间大床房含双早，每晚预算 1500 元左右。

询价助手会自动解析需求，填入右侧表单，并可能给出推荐酒店。您也可以上传行程单、名单等附件：

- 单次发送最多 3 张图片，单次对话最多 15 个附件；
- 单张图片不超过 5MB，单个文件不超过 10MB；
- 支持图片、PDF、Word、Excel、TXT 格式。

点击「清空」可以清除对话记录；如果同时勾选「同时清空右侧询价信息」，右侧表单也会一起清空。

:::tip
AI 解析的结果仅作为填写辅助，提交前请务必核对右侧表单中的目的地、日期和房间信息。
:::

### 右侧：询价信息表单 {#form}

**基础信息**

| 字段 | 说明 |
| --- | --- |
| 目的地 / 酒店 | 输入目的地、区域或具体酒店名称 |
| 入离日期 | 入住日期和离店日期，离店日期需晚于入住日期 |
| 预算（间夜） | 每间每晚的期望价格，详见[预算怎么填](#budget) |

**房间信息**

点击「添加房间」可以添加多组房间需求，每组包括：

- 房型：标准房、豪华房、家庭房、套房等，默认「不限」；
- 床型：大床、双床、单人床，默认「不限」；
- 餐型：不含早、含单早、含双早，默认「不限」；
- 入离日期：同一次询价中不同房间可以有不同日期；
- 间数，以及每间的入住人数（含儿童时需填写儿童年龄）。

**其他信息**

- 补充说明：特殊要求，例如高楼层、无烟房、相邻房间、提前入住等；
- 附件：支持 .pdf、.jpg、.png、.jpeg、.webp，也可以直接粘贴截图；
- 联系人、联系人电话：销售有问题时会联系此人。

## 预算怎么填 {#budget}

- 预算按**每间每晚**填写，不是整单总价；
- 表单中没有币种选项，请在补充说明中写明币种，例如「预算 1500 人民币/间夜」或「预算 200 美元/间夜」，避免理解偏差；
- 预算只是参考，销售会尽量在预算内匹配，但最终价格以报价方案为准；
- 不确定预算时可以填写一个大致区间的中间值，并在补充说明里写上可接受的范围。

## 提交询价 {#submit}

填写完成后点击「提交询价」。常见的校验提示：

| 提示 | 处理方式 |
| --- | --- |
| 请填写目的地、酒店或具体住宿需求 | 至少填写目的地或酒店，或在对话中描述需求 |
| 离店日期必须晚于入住日期 | 调整入离日期 |
| 已超过最早入住日期 | 入住日期已过，请重新选择 |
| 请检查每个房间的间数、入住人数、入离日期及儿童年龄 | 逐行检查房间信息是否填写完整 |
| 当前企业状态暂不支持提交新询价，请联系客户经理 | 企业状态异常，联系客户经理处理 |

提交成功后弹出「询价已提交」，显示询价编号。点击「查看询价」进入询价详情，或点击「继续询价」发起下一单。

## 跟进询价进度 {#inquiry-list}

点击左侧菜单「询价中心 → 询价管理」，可以看到所有询价单。顶部搜索框支持按询价单号或酒店名称搜索。

### 询价状态 {#inquiry-status}

| 状态 | 含义 | 您需要做什么 |
| --- | --- | --- |
| 待处理 | 询价已提交，销售正在处理 | 等待报价方案 |
| 待补充 | 需求信息不完整，销售需要您补充 | 打开询价详情，按销售要求补充信息 |
| 已完成 | 询价已处理完成 | 查看并确认报价方案 |
| 已关闭 | 询价已关闭，不再处理 | 如仍有需求，请重新发起询价 |

列表中每行可以展开，查看房间明细（房型、床型、间数、入住人数、特殊要求）以及该询价下的报价方案。

### 询价详情 {#inquiry-detail}

询价详情包括需求信息、入住信息、原始需求、补充需求和附件。页面底部的「动态」记录了询价的处理过程，您可以在这里**添加备注**，与销售沟通补充信息。

## 确认报价方案 {#quotation}

点击左侧菜单「询价中心 → 报价方案」，或在询价详情右侧查看报价方案。

### 方案状态 {#quotation-status}

| 状态 | 含义 |
| --- | --- |
| 待确认 | 销售已出具方案，等待您确认 |
| 已确认 | 您已接受方案，销售将继续跟进预订 |
| 已作废 | 方案已失效，不能再确认 |

### 看懂报价方案 {#quotation-fields}

| 字段 | 说明 |
| --- | --- |
| 方案编号 / 询价编号 | 方案所属的询价单 |
| 酒店信息、房型、床型、含餐情况 | 方案对应的具体房型 |
| 入离日期 / 间夜、入住人数（每间） | 入住安排 |
| 是否可退改 | 确认后能否取消或修改 |
| 预留截止日期 | 销售为您保留房间的截止时间，超过后价格和房态可能变化 |
| 每晚均价、方案金额 | 每晚平均价格和方案总金额 |

方案详情中还可以查看每晚价格（每间）、取消政策、方案备注和附件。

### 确认操作 {#confirm}

1. 打开方案详情，点击「确认方案」；或在方案列表中勾选多个方案批量确认。
2. 在弹窗中核对报价方案摘要，可选填备注。
3. 点击确认后提示「你已接受方案，销售将继续跟进后续确认。」；批量确认时提示「已确认 N 个报价方案」。

:::caution[请在预留截止日期前确认]
超过预留截止日期后，酒店可能不再保留房间或调整价格。请留意方案中的预留截止日期，尽早确认。
:::

以下情况无法确认方案：

| 提示 | 原因 |
| --- | --- |
| 该方案当前不可确认 | 方案不是「待确认」状态（已确认或已作废） |
| 请先补充询价信息后再确认方案 | 对应的询价处于「待补充」状态 |
| 询价已关闭，无法确认方案 | 对应的询价已关闭 |
| 当前企业状态暂不支持接受方案，请联系客户经理 | 企业状态异常 |

报价确认后，可以在[订单列表](/manual/orders/list/)查看订单。

## 常见问题 {#faq}

**对报价不满意怎么办？**
系统中不提供拒绝或还价按钮。请在询价详情的「动态」中添加备注说明您的意见，或直接联系销售，销售会重新出具方案。

**提交后还能修改询价内容吗？**
可以在询价详情的「动态」中添加备注补充或更正需求；如变动较大，建议重新发起询价。

**一次询价能要多家酒店的报价吗？**
从酒店页面或待询清单发起时只能选一家酒店。如果希望销售推荐多家酒店，请使用人工询价描述需求。

**多久能收到报价？**
工作日 9:00–18:00 内销售会尽快处理；紧急需求请在补充说明中注明，并直接联系您的专属客服。
