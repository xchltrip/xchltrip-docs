## 功能说明

系统登录模块支持多种登录方式，包含账号密码登录、验证码登录、微信扫码登录，同时配备忘记密码重置功能，为合规用户提供多渠道系统准入方式，拦截无效账号登录行为，保障系统访问安全。

## 适用场景

已完成系统注册的有效用户，可根据自身使用习惯，选择对应方式登录 OMS 系统；账号密码遗忘时，可通过忘记密码功能完成密码重置。

## 操作路径

打开小草互联旅游酒店询价系统 OMS 客户端登录页面，选择对应登录方式完成系统登录，或执行密码重置操作。

## 页面说明

### 登录页面

支持账号密码登录、验证码登录、微信扫码登录三种登录方式，并提供忘记密码入口。

## 操作步骤

### 登录页面 - 账号密码登录

![账号密码登录页面](/images/manual/oms-login-password.png)

1. 输入已注册且有效的电话号码或邮箱
2. 输入对应账号密码
3. 点击【登录】按钮进入系统

:::note
账号密码登录支持手机号、邮箱两种账号形式，仅已注册、状态有效的账号可登录，无效账号无法进入系统并触发提示。
:::

### 登录页面 - 验证码登录

![验证码登录页面](/images/manual/oms-login-code.png)

1. 输入已注册且有效的电话号码
2. 点击【获取验证码】，输入收到的短信验证码
3. 点击【登录】按钮进入系统

:::note
验证码登录仅支持手机号账号，需保证手机号已注册且状态有效。
:::

### 登录页面 - 微信扫码登录

![微信扫码登录页面](/images/manual/oms-login-wechat.png)

1. 切换至微信扫码登录页面
2. 使用微信扫描页面二维码
3. 已绑定账号：扫码验证通过后直接登录对应账号
4. 未绑定账号：扫码后根据提示完成账号绑定，绑定成功后进入系统

:::note
微信绑定仅支持绑定已注册的有效账号，若绑定账号无效，无法登录进入系统。
:::

### 登录页面 - 忘记密码

![忘记密码页面](/images/manual/oms-login-forgot.png)

1. 点击登录页面【忘记密码】选项
2. 根据页面提示输入注册手机号或邮箱
3. 获取验证信息并完成身份校验
4. 输入并设置新密码，完成密码重置

:::note
忘记密码功能支持用户自主重置登录密码，重置后可使用新密码登录系统。
:::

## 关键限制说明

- 状态限制：仅已注册且状态有效的账号可登录系统，无效账号登录会触发系统提示，禁止进入系统；若所属企业账号被冻结，企业下所有账号均无法登录系统
- 权限限制：无
- 前置条件：需拥有小草互联旅游酒店询价系统 OMS 有效注册账号

## 常见问题

**Q：账号密码登录支持哪些账号形式？**

A：支持已注册且有效的电话号码、邮箱两种账号形式登录。

**Q：验证码登录可以使用邮箱账号吗？**

A：不可以，验证码登录仅支持已注册的有效电话号码登录。

**Q：微信扫码登录提示无法进入系统是什么原因？**

A：多为绑定的账号未注册、账号状态无效，或扫码未完成账号绑定导致。

**Q：无效账号尝试登录会有什么提示？**

A：系统会弹出对应提示，同时拦截登录操作，禁止进入系统；企业冻结状态下，全员账号均会被拦截登录。
