小草互联trip酒店询价系统面向已开通企业账号的客户使用。本文介绍如何登录系统、忘记密码时如何找回，以及登录时可能遇到的各类提示。

## 登录入口 {#entry}

1. 在浏览器中打开小草互联trip官网，点击「登录」进入登录页。
2. 登录页默认显示**微信扫码登录**；点击登录框右上角的切换图标，可以在「微信扫码登录」和「密码 / 验证码登录」之间切换。
3. 登录成功后，系统默认进入「业务 → 酒店查询」页面。

## 登录方式 {#methods}

系统支持三种登录方式，无论使用哪一种，都需要先勾选「我已阅读并同意 平台服务协议 和 隐私政策」。未勾选时会提示「请先阅读并同意平台服务协议和隐私政策」，微信二维码也不会加载。

### 微信扫码登录 {#wechat}

1. 勾选服务协议后，页面显示登录二维码。
2. 打开手机微信，使用「扫一扫」扫描二维码。
3. 扫码后页面提示「已扫码，请在手机上确认」，在手机上点击确认授权。
4. 页面提示「授权成功，正在登录…」后自动进入系统。

扫码过程中可能看到的提示：

| 页面提示 | 说明与处理 |
| --- | --- |
| 二维码加载中… | 正在生成二维码，请稍候 |
| 二维码已过期 | 二维码有效期已过，点击「刷新」重新获取 |
| 微信扫码暂不可用，请使用账号密码登录 | 微信服务暂时不可用，请切换为密码或验证码登录 |

**首次使用微信登录**：如果该微信还没有绑定系统账号，扫码后会进入「绑定账号」页面。按提示输入已开通的手机号或邮箱完成绑定，之后即可直接扫码登录。

### 密码登录 {#password}

1. 切换到「密码 / 验证码登录」，选择「密码登录」页签。
2. 输入**手机号或邮箱**，以及登录密码。
3. 勾选服务协议，点击「登录」。

如果密码输入错误，系统会要求完成**滑块验证**（向右滑动解锁）后才能再次登录；未完成时会提示「请先完成滑块验证」。

### 验证码登录 {#sms}

1. 选择「验证码登录」页签，输入手机号或邮箱。
2. 点击「获取验证码」，页面提示「验证码已发送」，按钮进入 60 秒倒计时。
3. 输入收到的验证码，勾选服务协议，点击「登录」。

:::note
手机验证码目前仅支持中国大陆手机号（+86）。海外手机号用户请使用邮箱接收验证码，或使用密码登录。
:::

### 账号填写规则 {#account-rules}

| 情况 | 提示 |
| --- | --- |
| 未填写账号 | 请输入手机号或邮箱 |
| 手机号格式不正确（需为 1 开头的 11 位数字） | 请输入正确的手机号 |
| 邮箱格式不正确 | 请输入正确的邮箱 |

## 记住我 {#remember}

勾选「记住我」后，浏览器会在本机保存您的账号和密码，下次打开登录页时自动填入。

:::caution
在公用电脑、会议室电脑或他人设备上登录时，**请不要勾选「记住我」**，使用完毕后及时退出登录。
:::

## 忘记密码 {#reset-password}

1. 在登录页点击「忘记密码？」。
2. 输入手机号或邮箱，点击获取验证码并填写。
3. 输入**新密码**和**确认新密码**。
4. 提交后页面提示「密码已重置，请使用新密码登录」，返回登录页使用新密码登录。

新密码规则：

- 长度 8–20 位；
- 需为字母、数字和符号的组合；
- 两次输入必须一致，否则提示「两次输入的密码不一致，请核对后重新输入」。

如果收到的是重置密码邮件，点击邮件中的链接后，填写邮箱验证码和新密码即可完成重置。邮件链接失效时，请回到登录页重新发起「忘记密码」。

## 登录后的账号状态提示 {#account-status}

如果企业或账号状态异常，登录后不会进入系统，而是显示对应的状态页面：

| 状态页面 | 含义 | 处理方式 |
| --- | --- | --- |
| 企业审核中，请耐心等待 | 企业注册申请已提交，正在审核 | 等待审核结果，审核通过后即可正常使用 |
| 抱歉！您的企业申请已被驳回 | 企业资料审核未通过 | 根据驳回原因修改资料后重新提交申请 |
| 抱歉！您的企业已被冻结 | 企业整体被暂停使用 | 联系您的客户经理了解原因 |
| 抱歉！您的账号已被冻结 | 当前个人账号被暂停使用 | 联系企业主账号管理员或客户经理 |

## 子账号与邀请激活 {#sub-account}

企业主账号可以在「机构管理 → 子账号管理」中为同事开通子账号。被邀请的同事会收到邀请链接，打开后按提示完成激活即可登录。邀请链接失效时，请联系主账号管理员重新发送邀请。

## 退出登录 {#logout}

1. 点击页面右上角的头像。
2. 在下拉菜单中选择「退出登录」。
3. 在弹窗「是否确认退出登录？」中点击确认。

**登录过期**：长时间未操作时，系统会先尝试自动续期；续期失败时会自动跳转回登录页，重新登录即可，已提交的询价和订单数据不会丢失。

## 注意事项 {#notice}

- 请妥善保管账号密码，不要将账号借给他人使用；每位同事建议使用独立的子账号。
- 定期修改密码，避免使用与其他网站相同的密码。
- 验证码仅用于本人登录，任何人向您索要验证码都请拒绝。
- 发现账号异常登录时，请立即修改密码并联系客户经理。

登录后可以[查询酒店](/manual/hotel-search/search/)，或直接[发起询价](/manual/quotation/create/)。

## 常见问题 {#faq}

**收不到验证码怎么办？**
请确认手机号或邮箱填写正确；邮箱请检查垃圾邮件文件夹；60 秒后可以重新获取。手机号非中国大陆号码时，请改用邮箱或密码登录。

**提示「请输入正确的手机号」，但号码没有错？**
手机号需为 1 开头的 11 位数字，请检查是否多输入了空格、区号或 +86 前缀。

**二维码一直不出现？**
请先勾选服务协议；如仍未出现，刷新页面或切换为密码登录。

**换了手机号还能登录吗？**
可以使用绑定的邮箱或微信登录，然后联系客户经理或主账号管理员更新手机号。
