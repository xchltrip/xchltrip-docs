本文介绍介绍如何自主维护个人账号基础信息与登录权限，支持修改姓名、手机号、邮箱、密码及微信绑定解绑。

## 功能说明

账号管理模块用于用户自主维护个人账号基础信息与登录权限，支持修改姓名、手机号、邮箱、登录密码，同时提供微信账号绑定与解绑功能，可灵活更新账号信息、调整登录方式，保障账号信息准确、登录方式可控。

## 适用场景

用户个人信息变更、需要更新账号绑定信息、更换登录账号（手机号/邮箱）、重置登录密码、开通或关闭微信扫码登录权限时使用。

## 操作路径

登录小草互联旅游酒店询价系统 OMS 客户端，进入账号管理页面，按需选择对应功能完成账号信息维护、微信绑定解绑、密码修改等操作。

## 页面说明

### 账号管理页面

![账号管理页面](/images/manual/oms-account-info.png)

说明：页面自动回显当前账号对应的企业信息，支持查看企业基础资料。

## 操作步骤

### 账号管理页面 - 修改姓名

![修改姓名弹窗](/images/manual/oms-account-name.png)

1. 进入【账号管理】页面
2. 点击姓名编辑按钮
3. 输入最新姓名信息
4. 点击【保存】完成修改

:::note
修改后页面实时更新展示最新姓名信息。
:::

### 账号管理页面 - 修改号码

![修改号码弹窗](/images/manual/oms-account-phone.png)

1. 进入【账号管理】页面
2. 点击手机号码编辑按钮
3. 输入新手机号码并完成验证码校验
4. 点击【保存】完成号码修改

:::note
手机号码修改完成后，后续登录需使用新号码进行登录，旧号码失效。
:::

### 账号管理页面 - 修改邮箱

![修改邮箱弹窗](/images/manual/oms-account-email.png)

1. 进入【账号管理】页面
2. 点击邮箱编辑按钮
3. 输入新邮箱账号并完成身份校验
4. 点击【保存】完成邮箱修改

:::note
邮箱修改完成后，后续登录需使用新邮箱进行登录，旧邮箱失效。
:::

### 账号管理页面 - 绑定/解绑微信

![绑定微信弹窗](/images/manual/oms-account-wechat.png)

1. 进入【账号管理】页面微信绑定区域
2. 未绑定状态：点击【绑定微信】，扫码完成绑定操作
3. 已绑定状态：点击【解绑微信】，确认后解除微信与账号关联

:::note
绑定微信后，可通过微信扫码快速登录当前账号；解绑微信后，该微信扫码将无法登录此账号。
:::

### 账号管理页面 - 修改密码

![修改密码弹窗](/images/manual/oms-account-password.png)

1. 进入【账号管理】页面
2. 点击【修改密码】功能按钮
3. 输入当前旧密码
4. 输入全新密码，确认新密码
5. 点击【保存】完成密码更新

:::note
新密码不允许与旧密码一致，修改成功后需使用新密码登录系统，旧密码即刻失效。
:::

## 关键限制说明

- 状态限制：手机号、邮箱修改生效后，旧登录账号失效，仅新账号可登录
- 安全限制：新密码不可与旧密码重复，系统自动拦截重复密码设置；账号密码每 180 天需主动更新，超时未修改密码，系统将强制弹窗要求用户修改密码，未完成密码修改不允许进入和使用系统
- 权限限制：仅当前登录账号本人可操作个人账号信息维护
- 前置条件：账号需为正常有效、审核通过状态，且所属企业未处于冻结状态

## 常见问题

**Q：修改手机号或邮箱后，还能用旧账号登录吗？**

A：不可以，修改完成后旧号码、旧邮箱失效，必须使用新的号码或邮箱登录系统。

**Q：微信绑定后有什么作用？**

A：绑定微信后，可直接使用对应微信扫码快速登录当前系统账号。

**Q：解绑微信后还能扫码登录吗？**

A：不能，解绑后该微信与账号解除关联，无法通过扫码登录该账号。

**Q：修改密码时可以设置和原来一样的密码吗？**

A：不可以，系统限制新密码与旧密码不能相同，需设置全新密码。

**Q：账号长期未改密码会有什么限制？**

A：系统强制要求账号密码每 180 天更新一次，若 180 天未修改密码，登录后会触发强制改密弹窗，必须完成密码修改，否则无法正常使用系统；同时若企业状态为冻结，全员账号也将无法登录使用系统。

**Q：账号管理页面是否可以查看企业信息？**

A：可以，页面会自动回显当前账号对应的企业相关信息；若企业状态为冻结，全员账号将无法登录使用系统。
