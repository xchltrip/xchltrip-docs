酒店查询帮助您快速找到合适的酒店，查看房型、餐型、取消政策和参考价格，并把心仪的房型加入待询清单，一次性发起询价。

## 查询入口 {#entry}

登录后点击左侧菜单「业务 → 酒店查询」，进入酒店查询页面。登录成功后系统默认也会打开这个页面。

页面由三部分组成：

- **顶部搜索栏**：填写目的地、日期和住客信息；
- **左侧筛选栏**：按星级、餐型、床型、设施缩小范围；
- **右侧结果列表**：展示符合条件的酒店，可排序、收藏和发起询价。

## 查询条件 {#filters}

| 条件 | 是否必填 | 说明 |
| --- | --- | --- |
| 目的地 | 必填 | 可输入城市、商圈、景点或酒店名称，从下拉建议中选择 |
| 关键词 | 选填 | 输入品牌或酒店名，进一步缩小结果 |
| 入住日期 / 离店日期 | 必填 | 离店日期需晚于入住日期 |
| 房间及住客 | 必填 | 房间 1–8 间；成人 1–20 人（18 岁及以上）；儿童 0–10 人（0–17 岁） |

填写步骤：

1. 在「目的地」输入框中输入关键字，下拉建议会按**目的地、酒店、景点**分组显示，点击选择一项。
2. 选择入住日期和离店日期。
3. 点击「房间及住客」，设置房间数、成人数和儿童数。
4. 如有儿童，需要为**每位儿童选择年龄**，否则会提示「请选择每位儿童的年龄」。
5. 点击查询，右侧显示「找到 N 家酒店」。

:::tip[儿童年龄为什么必填]
不同酒店对儿童的加床、早餐和入住政策不同，填写准确的年龄可以让报价更准确，避免入住时产生额外费用。
:::

### 目的地相关提示 {#destination-tips}

| 提示 | 说明与处理 |
| --- | --- |
| 请选择目的地 | 需要从下拉建议中选择，不能只输入文字 |
| 当前目的地无法搜索，请选择所属城市 | 所选区域范围过小，请改选所在城市 |
| 酒店数据准备中，选择后自动加载 | 该目的地数据正在加载，稍等即可显示 |
| 当前暂不可搜索 | 该目的地暂未开放，可直接[发起人工询价](/manual/quotation/create/) |

## 筛选与排序 {#sort}

### 左侧筛选 {#side-filters}

- **酒店星级**：不限、二星 / 经济型、三星 / 舒适、四星 / 高档、五星 / 豪华；
- **餐型**：如含早、不含早等；
- **床型**：如大床、双床等；
- **酒店设施**：点击「更多」展开全部设施，点击「重置」清空筛选。

### 结果排序 {#ordering}

结果列表右上角可切换排序方式：默认排序、星级高→低、星级低→高、距离近→远、已收藏的优先。

:::note
目前不支持按价格筛选。如果对价格有明确要求，可以在发起询价时填写[预算](/manual/quotation/create/#budget)。
:::

## 查看结果列表 {#results}

每张酒店卡片包含：

- 酒店名称、星级和酒店简介；
- **参考价格**：显示「XXX 起/间夜」，即该酒店在所选日期下的最低参考价；
- 显示「价格暂不可用」或「详情页询价」时，表示暂无公开价格，可直接发起询价获取报价；
- 「收藏」按钮：收藏后可在「个人中心 → 我的收藏」中快速找到；
- 「发起询价」按钮：直接针对这家酒店发起询价。

页面侧边的**浏览历史**会记录您最近查看过的酒店，方便来回比较。

没有匹配结果时，页面提示「暂无匹配酒店，请调整筛选条件重试。」，可以放宽星级、设施等筛选条件，或更换目的地。

## 酒店详情 {#detail}

点击酒店卡片进入酒店详情页，顶部显示住宿类型、连锁集团、酒店品牌、住客点评评分（超棒、很好、不错、一般），以及「发起询价」和「收藏」按钮。

详情页分为四个页签：

| 页签 | 内容 |
| --- | --- |
| 房型价格 | 所有可选房型及参考价格 |
| 酒店介绍 | 酒店概况、位置和特色 |
| 酒店设施 | 设施与服务清单 |
| 酒店政策 | 入住离店时间、儿童及加床等政策 |

### 房型价格 {#rooms}

房型列表上方可以按**房型、床型、餐型**筛选，或只看「免费取消」的房型。每一行展示：

- 床型摘要；
- 餐型（是否含早及份数）；
- 取消政策；
- 价格 / 间夜（标注「该房型最低价」的为该房型下最便宜的选项；「暂无公开报价」表示需要询价）；
- 询价按钮。

点击房型名称可以打开「房间详情」，查看房型概述，也可以在弹窗里直接发起询价。

:::caution
床型属于**入住请求**，酒店会尽量安排，但不保证一定满足。对床型有严格要求时，请在询价的补充说明中注明。
:::

### 取消政策说明 {#cancel-policy}

| 标签 | 含义 |
| --- | --- |
| 免费取消 | 在规定时间前取消可全额退款 |
| 限时免费取消 | 在截止时间前可免费取消，过后按政策扣费 |
| 部分退款 | 取消后只能退还部分费用 |
| 不可取消 | 预订后不能取消，也不退款 |

把鼠标移到取消政策标签上，会弹出「取消政策说明」，以时间轴形式展示各时间段对应的全额退款、部分退款或不可退款。

## 加入待询清单 {#pending-list}

在房型列表中点击询价按钮，页面提示「已加入待询清单」。待询清单会收集您选中的房型，确认后可以一次性发起询价。

- 一次询价**只能选择一家酒店**，如需多家酒店报价，请分别发起；
- 发起前请核对清单中的房型、日期和入住人数。

查到合适的酒店后，可以[发起询价](/manual/quotation/create/)。

## 常见问题 {#faq}

**为什么搜不到某家酒店？**
请检查目的地是否选择了酒店所在城市，并清空关键词和筛选条件再试。如果仍然找不到，可以通过[人工询价](/manual/quotation/create/#entry)直接描述酒店名称。

**页面上的价格就是最终价格吗？**
不是。列表和详情页的价格仅供参考，最终价格以销售给出的报价方案为准。

**价格显示「详情页询价」是什么意思？**
表示该酒店暂无公开价格，点击「发起询价」后，销售会为您单独报价。

**能直接在页面上预订吗？**
不能。系统采用询价模式，请发起询价，确认报价方案后由销售为您安排预订。

**有问题找谁？**
详情页底部可以联系您的专属客服，服务时间为工作日 9:00–18:00。
