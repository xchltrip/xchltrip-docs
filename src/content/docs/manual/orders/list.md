本文介绍如何使用OMS客户端酒店订单模块，包含订单查看、筛选、订单列表、订单详情及相关注意事项说明

## 功能说明 {#order-intro}
报价方案确认后，销售完成酒店预订即可生成酒店订单。本模块支持订单查询、多维度筛选、查看订单明细、回溯关联询价与报价方案，可查看订单进度、入住信息、结算相关金额，实现订单全流程查看管理。

## 适用场景 {#order-scene}
确认报价方案生成订单后，需要查看订单列表、筛选定位目标订单、查看房间及结算信息、核对入住资料、回溯原始询价报价单据时使用。

## 操作路径 {#order-path}
登录小草互联旅游酒店询价客户端OMS，点击左侧菜单【订单管理 → 酒店订单】进入订单列表页面；可通过状态、关键字、列筛选找到目标订单，点击订单编号进入订单详情页查看完整信息。

## 页面说明 {#order-page}
### 酒店订单列表页面 {#order-list-page}
订单列表顶部为状态页签，页签展示各状态订单数量；下方为订单数据表格，支持展开查看房间明细。

![酒店订单列表页面](/images/manual/orders-list.png)

#### 按状态筛选 {#status-tabs}
| 状态 | 含义 |
| --- | --- |
| 全部 | 所有订单 |
| 处理中 | 销售正在为您向酒店预订、确认 |
| 待完成 | 预订已确认，等待入住或离店后完结 |
| 已完成 | 订单已履约完成 |
| 已关闭 | 订单已取消或关闭 |

#### 关键字搜索 {#keyword}
在「关键字搜索」框中输入订单编号、酒店名称等关键字，快速定位订单。

#### 列筛选与排序 {#column-filter}
表格的列标题支持筛选和排序。例如：
- 按「入住日期」排序，查看近期即将入住的订单；
- 按「结算方式」筛选，只看挂账或现结订单；
- 按「创建时间」排序，查看最新的订单。

> :::note
> 没有符合条件的订单时，页面显示「暂无符合条件的订单」，请清空筛选条件后重试。
> :::

#### 看懂订单列表 {#columns}
| 字段 | 说明 |
| --- | --- |
| 状态 | 订单当前所处状态，见上文 |
| 订单编号 | 订单的唯一编号，与销售沟通时请提供 |
| 关联账单 | 订单所属的账单，可在「账单管理」中查看 |
| 酒店信息、城市 | 预订的酒店及所在城市 |
| 入住日期 / 间夜 | 入住日期，以及「N 间 N 晚」 |
| 结算方式 | 现结、挂账或预留，见下表 |
| 订单金额 | 订单总金额 |
| 应结算金额 | 您需要结算的金额 |
| 累计收款 / 累计付款 | 已经收到和已经支付的金额 |
| 应结算余额 | 还未结清的金额 |
| 创建时间 | 订单生成时间 |

##### 结算方式 {#settlement}
| 结算方式 | 含义 |
| --- | --- |
| 现结 | 按单结算，通常需要在约定时间内付款 |
| 挂账 | 先入住，按合同约定的账期统一结算 |
| 预留 | 房间暂时为您保留，需在预留截止日期前确认 |

:::note
结算方式和账期以贵司与小草互联trip签订的合同为准，如有疑问请联系客户经理。
:::

### 酒店订单详情页面 {#order-detail-page}
点击订单编号进入酒店订单详情。顶部展示订单状态、结算方式、入离日期和下单用户；正文展示酒店、房型、价格、入住人、特殊需求、附件、处理动态；右侧展示联系人、企业信息以及可跳转的询价编号、方案编号；页面右上角提供分享、全屏功能按钮。

![酒店订单详情页面](/images/manual/order-detail-page.png)

| 区块 | 内容 |
| --- | --- |
| 酒店信息 | 酒店名称、地址等，可一键复制，方便发给入住人 |
| 房型信息 | 房型、床型、餐型、间数 |
| 每晚价格（每间） | 每晚的价格明细 |
| 入住人信息 | 国籍、入住人数和入住人姓名 |
| 特殊需求 | 下单时提出的特殊要求 |
| 附件 | 确认单等相关文件 |
| 动态 | 订单处理记录 |

:::tip[入住前核对]
入住前请在订单详情中核对入住人姓名、入离日期和房型。入住人姓名需与证件一致，如有错误请尽快联系销售修改。
:::

## 核心页面规则 {#order-rule}
- 列表页签规则：状态页签会实时展示对应状态订单统计数量；
- 筛选排序规则：支持状态页签、关键字搜索、表格列筛选排序，多条件可叠加生效；
- 展开规则：列表行首展开按钮可查看房间明细；
- 跳转规则：订单详情内可点击询价编号、方案编号回溯上游单据；
- 分享规则：分享按钮复制订单链接，仅拥有系统账号权限的人员可打开访问。

## 完整操作步骤 {#order-step}
### 进入并查看订单列表 {#order-step-list}
1. 登录OMS客户端，点击左侧菜单【订单管理 → 酒店订单】；
2. 通过顶部状态页签筛选对应状态订单；
3. 使用关键字搜索框输入订单号、酒店名称快速检索；
4. 使用列表表头筛选、排序，定位目标订单；
5. 点击行首展开按钮查看房间明细。

### 查看订单详情 {#order-step-detail}
1. 在订单列表，点击目标订单的【订单编号】进入订单详情页；
2. 查看酒店、房型、价格、入住人、特殊需求、附件以及动态记录；
3. 查看右侧栏联系人、关联询价编号、方案编号，可点击跳转至上游单据；
4. 需要对外给到同事查看，点击右上角【分享】复制订单链接；
5. 点击【全屏】按钮放大查看详情内容。

## 关键限制说明 {#order-limit}
- 操作权限：订单链接仅限拥有系统账号权限用户访问，不可转借账号给外部人员；
- 变更限制：系统页面无取消、修改订单按钮，变更需要联系销售/客服处理；
- 导出限制：订单列表页面暂不支持直接导出，对账需前往账单管理查看或联系客户经理；
- 预留订单限制：预留订单超过预留截止日期，酒店可能释放房间；
- 退改限制：标记不可退改的订单确认后，无法取消修改，相关费用照常结算。

## 注意事项 {#order-notice}
- 请关注订单的**预留截止日期**，预留订单超过截止日期仍未确认，房间可能被释放；
- 「是否可退改」显示不可退改的订单，确认后无法取消或修改，产生的费用需要照常结算；
- 订单链接仅限有权限的系统账号查看，请勿将账号借给他人。

## 常见问题 {#order-faq}
**Q：如何取消或修改订单？**
A：系统中暂不提供取消或修改订单的按钮。请联系您的专属客服或销售处理，并提供订单编号，服务时间为工作日 9:00–18:00。是否可以免费取消，取决于订单的取消政策和「是否可退改」。

**Q：为什么确认了报价方案却没有看到订单？**
A：确认方案后，销售需要向酒店完成预订才会生成订单，请稍后刷新。如长时间未生成，可以在[报价方案](/manual/quotation/create/#quotation)中查看方案状态，或联系销售。

**Q：预留截止日期是什么意思？**
A：这是酒店为您保留房间的最晚时间。在此之前需要确认入住安排，否则房间可能被释放或价格变化。

**Q：订单金额和应结算金额为什么不一样？**
A：订单金额是订单总价，应结算金额是按结算规则需要支付的金额，两者可能因调整、退款等原因不同。具体以账单为准。

**Q：能导出订单吗？**
A：订单列表暂不支持导出。需要对账时，请在「账单管理 → 酒店账单明细」中查看，或联系客户经理获取对账单。
