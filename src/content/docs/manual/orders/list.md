报价方案确认后，销售会为您完成预订并生成酒店订单。在订单列表中，您可以随时查看订单进度、入住信息和结算金额。

## 查看订单 {#entry}

点击左侧菜单「订单管理 → 酒店订单」，进入订单列表。

列表顶部是**状态页签**，每个页签后面显示该状态下的订单数量；下方是订单表格，点击行首的展开按钮可以查看房间明细，点击订单编号进入订单详情。

## 筛选订单 {#filters}

### 按状态筛选 {#status-tabs}

| 状态 | 含义 |
| --- | --- |
| 全部 | 所有订单 |
| 处理中 | 销售正在为您向酒店预订、确认 |
| 待完成 | 预订已确认，等待入住或离店后完结 |
| 已完成 | 订单已履约完成 |
| 已关闭 | 订单已取消或关闭 |

### 关键字搜索 {#keyword}

在「关键字搜索」框中输入订单编号、酒店名称等关键字，快速定位订单。

### 列筛选与排序 {#column-filter}

表格的列标题支持筛选和排序。例如：

- 按「入住日期」排序，查看近期即将入住的订单；
- 按「结算方式」筛选，只看挂账或现结订单；
- 按「创建时间」排序，查看最新的订单。

没有符合条件的订单时，页面显示「暂无符合条件的订单」，请清空筛选条件后重试。

## 看懂订单列表 {#columns}

| 字段 | 说明 |
| --- | --- |
| 状态 | 订单当前所处状态，见上文 |
| 订单编号 | 订单的唯一编号，与销售沟通时请提供 |
| 关联账单 | 订单所属的账单，可在「账单管理」中查看 |
| 酒店信息、城市 | 预订的酒店及所在城市 |
| 入住日期 / 间夜 | 入住日期，以及「N 间 N 晚」 |
| 结算方式 | 现结、挂账或预留，见下表 |
| 订单金额 | 订单总金额 |
| 应结算金额 | 您需要结算的金额 |
| 累计收款 / 累计付款 | 已经收到和已经支付的金额 |
| 应结算余额 | 还未结清的金额 |
| 创建时间 | 订单生成时间 |

### 结算方式 {#settlement}

| 结算方式 | 含义 |
| --- | --- |
| 现结 | 按单结算，通常需要在约定时间内付款 |
| 挂账 | 先入住，按合同约定的账期统一结算 |
| 预留 | 房间暂时为您保留，需在预留截止日期前确认 |

:::note
结算方式和账期以贵司与小草互联trip签订的合同为准，如有疑问请联系客户经理。
:::

### 展开查看房间明细 {#rooms}

展开订单行可以看到每个房间的房型、床型、含餐情况、入住日期 / 间夜、入住人数（每间）、是否可退改、预留截止日期、每晚均价、小计和备注。

## 订单详情 {#detail}

点击订单编号进入酒店订单详情。顶部显示订单状态、结算方式、入离日期和下单用户，正文包括：

| 区块 | 内容 |
| --- | --- |
| 酒店信息 | 酒店名称、地址等，可一键复制，方便发给入住人 |
| 房型信息 | 房型、床型、餐型、间数 |
| 每晚价格（每间） | 每晚的价格明细 |
| 入住人信息 | 国籍、入住人数和入住人姓名 |
| 特殊需求 | 下单时提出的特殊要求 |
| 附件 | 确认单等相关文件 |
| 动态 | 订单处理记录 |

右侧信息栏显示联系人、联系电话、企业名称，以及该订单对应的**询价编号**和**方案编号**，点击可以回溯到原始询价和报价方案。

页面右上角的「分享」按钮会复制订单链接，方便发给同事查看（同事需要有系统账号并登录）；「全屏」按钮可以放大查看详情。

:::tip[入住前核对]
入住前请在订单详情中核对入住人姓名、入离日期和房型。入住人姓名需与证件一致，如有错误请尽快联系销售修改。
:::

## 注意事项 {#notice}

- 请关注订单的**预留截止日期**，预留订单超过截止日期仍未确认，房间可能被释放；
- 「是否可退改」显示不可退改的订单，确认后无法取消或修改，产生的费用需要照常结算；
- 订单链接仅限有权限的系统账号查看，请勿将账号借给他人。

如需了解登录相关问题，请查看[系统登录](/manual/getting-started/login/#notice)。

## 常见问题 {#faq}

**如何取消或修改订单？**
系统中暂不提供取消或修改订单的按钮。请联系您的专属客服或销售处理，并提供订单编号，服务时间为工作日 9:00–18:00。是否可以免费取消，取决于订单的取消政策和「是否可退改」。

**为什么确认了报价方案却没有看到订单？**
确认方案后，销售需要向酒店完成预订才会生成订单，请稍后刷新。如长时间未生成，可以在[报价方案](/manual/quotation/create/#quotation)中查看方案状态，或联系销售。

**预留截止日期是什么意思？**
这是酒店为您保留房间的最晚时间。在此之前需要确认入住安排，否则房间可能被释放或价格变化。

**订单金额和应结算金额为什么不一样？**
订单金额是订单总价，应结算金额是按结算规则需要支付的金额，两者可能因调整、退款等原因不同。具体以账单为准。

**能导出订单吗？**
订单列表暂不支持导出。需要对账时，请在「账单管理 → 酒店账单明细」中查看，或联系客户经理获取对账单。
