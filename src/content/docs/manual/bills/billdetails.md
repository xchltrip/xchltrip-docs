本文介绍如何OMS客户端酒店账单明细模块，包含账单列表筛选、账单详情各Tab查看、权限与只读限制说明

## 功能说明 {#bill-intro}
酒店账单明细列表用于查看当前企业的酒店账单信息。用户可以查看账单列表、账单状态及金额信息，并通过打开账单详情查看账单基本信息、账单内的订单明细和款项跟踪记录。
本模块为只读模块，仅支持查看，不提供收款、修改备注、开票或结算等操作。

## 适用场景 {#bill-scene}
- 企业用户需要查看当前企业的酒店账单。
- 企业用户需要了解账单的对账状态及应付、已付、未付金额。
- 企业用户需要查看账单包含的酒店订单。
- 企业用户需要查看账单对应的支付款项记录。

## 操作路径 {#bill-path}
登录小草互联旅游酒店询价客户端OMS，进入酒店账单明细列表页面；通过筛选、搜索定位目标账单，双击账单打开账单详情弹窗查看完整信息。

## 页面说明 {#bill-page}
### 酒店账单明细列表页面 {#bill-list-page}
用于展示当前企业的酒店账单明细，支持状态筛选、关键词搜索、账单日期范围筛选。

![酒店账单明细列表页面](/images/manual/bill-list-page.png)

**列表展示字段**
| 字段名称 | 字段说明 |
|---|---|
| 状态 | 展示账单当前状态，包括待对账、已对账 |
| 账单编号 | 账单对应的编号 |
| 账单名称 | 账单对应的名称 |
| 账单应付金额 | 当前账单应付金额 |
| 已付金额 | 当前账单已支付金额 |
| 未付金额 | 当前账单尚未支付金额 |
| 账单日期 | 账单对应的日期 |

**筛选功能**
- 状态筛选：支持按照待对账、已对账两种状态筛选账单。
- 关键词搜索：支持输入账单编号或账单名称进行模糊搜索。
- 账单日期筛选：支持选择账单日期范围进行筛选。

> :::note
> 空数据说明：当当前企业没有可查看的账单时，页面显示「暂无账单」。
> :::

### 账单详情弹窗 {#bill-detail-modal}
双击列表目标账单弹出账单详情弹窗，包含三个Tab：基本信息、账单明细、款项跟踪。

![账单详情弹窗](/images/manual/bill-detail-modal.png)

#### 基本信息 Tab {#bill-tab-base}
用于查看当前账单的基本信息。

![账单详情‑基本信息Tab](/images/manual/bill-tab-base.png)

**查看内容**
- 账单编号
- 账单名称
- 账单状态
- 账单日期
- 账单应付金额
- 已付金额
- 未付金额

#### 账单明细 Tab {#bill-tab-order}
用于查看当前账单包含的酒店订单明细。

![账单详情‑账单明细Tab](/images/manual/bill-tab-order.png)

**查看内容**
- 查看当前账单关联的订单明细。
- 账单明细采用销售视图展示。
- 明细行包含订单号时，可点击订单号跳转查看对应订单详情。

#### 款项跟踪 Tab {#bill-tab-payment}
用于查看当前账单对应的支付款项记录。

![账单详情‑款项跟踪Tab](/images/manual/bill-tab-payment.png)

**查看内容**
- 款项记录时间
- 款项金额
- 款项说明摘要

> :::note
> 款项跟踪仅支持查看，不提供收款操作，也不展示备注列。
> :::

## 核心页面规则 {#bill-rule}
- 数据隔离规则：仅展示当前登录所属企业可查看的账单，其他企业账单不可见；
- 账单状态规则：列表仅展示待对账、已对账，草稿账单不会展示；
- 打开详情规则：列表双击账单行唤起账单详情弹窗；
- 跳转规则：账单明细Tab内订单编号支持点击跳转至酒店订单详情；
- 异常提示规则：账单查询失败时展示「账单信息暂时无法加载，请稍后重试」，提供重新加载，不会混淆为空账单。

## 完整操作步骤 {#bill-step}
### 账单列表筛选查询 {#bill-step-list}
1. 登录OMS客户端，进入酒店账单明细列表页面；
2. 根据业务需要选择账单状态，筛选对应状态账单；
3. 在搜索框输入账单编号或者账单名称，搜索目标账单；
4. 选择账单日期范围，查询指定时间段账单；
5. 查看列表账单状态、应付、已付、未付等字段。

### 查看账单详情弹窗 {#bill-step-detail}
1. 在账单列表中，双击目标账单数据，打开账单详情弹窗；
2. 切换【基本信息】Tab，查看账单基础信息与金额；
3. 切换【账单明细】Tab，查看关联订单，点击订单号跳转订单详情；
4. 切换【款项跟踪】Tab，查看款项时间、金额、摘要记录；
5. 查看完毕关闭弹窗返回账单列表。

## 关键限制说明 {#bill-limit}
- 仅展示当前企业可查看的账单数据。
- 账单列表仅展示待对账、已对账两种状态，不展示草稿账单。
- 账单详情及款项跟踪均为只读，不支持修改或提交操作。
- 页面不提供结算申请、线下汇款、发票管理等入口。
- 账单列表不展示客户名称、备注、开票状态、账单周期、到期日、逾期信息等字段。
- 账单详情不展示返佣、内部成本、商务负责人、应收视图、工作日志、客户名、开票记录及开票金额等内部信息。
- 账单查询失败时，应显示「账单信息暂时无法加载，请稍后重试」，并支持重新加载，不得将查询失败显示为正常的空账单列表。

## 常见问题 {#bill-faq}
**Q：账单列表没有数据怎么办？**

A：当前企业没有可查看的待对账或已对账账单时，页面显示「暂无账单」。

**Q：页面提示账单信息暂时无法加载是什么原因？**

A：当账单信息查询失败或超时时，页面显示该错误提示，可重新尝试加载。

**Q：账单是否可以直接进行收款或开票操作？**

A：不可以。本模块仅提供账单信息查看，不提供收款、开票及结算操作。
